# Interop

Keeps the Rust crates compatible with the Java implementation.

- `vectors/` - JSON test vectors generated by the Java implementation: ids, values (including
  encrypted values), peer info, CWTs, crypto box, signatures, Boson strings. Regenerate them when
  a Java wire format changes; never edit them by hand.
- `java-node/` - scripts that start a Java super node, so `boson-dht` and `boson-higgs` run against
  the real implementation in integration tests.
